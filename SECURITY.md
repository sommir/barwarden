# Security Policy

## Supported versions

Security fixes are applied to the latest released version of Barwarden.

## Reporting a vulnerability

Please use GitHub's **Private Vulnerability Reporting** feature for this
repository. Do not open a public issue for a suspected vulnerability.

Include a minimal reproduction, affected version, impact assessment, and any
safe mitigation you identified. Do not include passwords, access tokens,
recovery codes, or real vault data. Reports are acknowledged as soon as
practicable, and disclosure timing will be coordinated after a fix is available.
